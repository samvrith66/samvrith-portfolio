# Samvrith Singh | Portfolio

Static site, no build step.

- index.html: the whole portfolio (HTML, CSS, JavaScript)
- three.min.js: Three.js r128, bundled locally
- vercel.json: Vercel settings

Fonts (Instrument Serif, Bebas Neue, JetBrains Mono) load from Google Fonts; the site falls back to system fonts if offline.

Run locally: `python3 -m http.server 8000` in this folder, then open http://localhost:8000
